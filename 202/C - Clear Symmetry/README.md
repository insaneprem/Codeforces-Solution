There are <span class="tex-span"><i>n</i></span> rows numbered from <span class="tex-span">1</span> to <span class="tex-span"><i>n</i></span> from top to bottom and <span class="tex-span"><i>n</i></span> columns numbered from <span class="tex-span">1</span> to <span class="tex-span"><i>n</i></span> from left to right in this matrix.
