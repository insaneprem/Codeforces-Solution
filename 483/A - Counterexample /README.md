A pair of numbers <span class="tex-span">{<i>a</i>, <i>b</i>}</span> is called <span class="tex-font-style-it">coprime</span> if the maximum number that divides both <span class="tex-span"><i>a</i></span> and <span class="tex-span"><i>b</i></span> is equal to one. </p><p>Your friend often comes up with different statements.
