They found <span class="tex-span"><i>n</i></span> red cubes and <span class="tex-span"><i>m</i></span> blue cubes. The game goes like that: the players take turns to choose a cube of some color (red or blue) and put it in a line from left to right (overall the line will have <span class="tex-span"><i>n</i> + <i>m</i></span> cubes). Your task is to calculate the score at the end of the game (Petya's and Vasya's points, correspondingly), if both boys are playing optimally well.
